Variáveis de Ambiente Recomendadas

Para colocar o bot no ar no Telegram com banco Neon e hospedagem Vercel:

  • DATABASE_URL: connection string PostgreSQL do Neon
  • TELEGRAM_BOT_TOKEN: token gerado no @BotFather
  • TELEGRAM_WEBHOOK_SECRET: segredo aleatório de validação
  • PAIRING_CODE: código secreto para vincular sua conta
  • PUBLIC_BASE_URL: URL HTTPS pública da aplicação

No terminal do seu projeto, utilize o script incluído: npm run set-webhook.

Poucos passos, mais contexto

Organizar pode ser simples.

O bot transforma pequenas anotações em uma visão clara do mês — sem pedir acesso às suas contas.

01

Defina seu mês

Informe sua renda, o total de contas fixas e quanto quer guardar. O bot calcula o teto mensal para os gastos.

02

Anote quando gastar

Escreva algo como “gastei R$ 50 no almoço” ou “uber 25”. O lançamento entra na categoria correspondente.

03

Ajuste suas caixinhas

Veja o saldo do mês, mude os limites e acompanhe metas como uma viagem ou uma reserva.

Privacidade sem complicação

Seu orçamento é seu.
O bot só ajuda a organizar.

O projeto foi pensado para uma única pessoa. Não pede acesso ao banco, não movimenta dinheiro e não precisa de senha bancária.

01
Acesso limitado

Depois do pareamento, só a conta autorizada pode usar o bot.

02
Dados essenciais

Valores, categorias, datas e descrições curtas ficam no banco do projeto.

03
Sem transferência

“Guardar” apenas registra o valor informado; o dinheiro continua onde está.

As mensagens também permanecem no seu chat do Telegram. Não envie senhas, dados de cartão, códigos de autenticação ou extratos.

Um projeto pessoal

Feito para começar sem mensalidade.

O bot usa a Bot API gratuita do Telegram. A hospedagem Vercel Hobby e o banco Neon Free podem começar nos planos gratuitos para uso pessoal.

↗
Gratuito não significa ilimitado.

Se os limites gratuitos forem atingidos, Vercel ou Neon podem pausar o serviço. Sem cartão cadastrado, não há cobrança automática; o bot pode ficar temporariamente indisponível. Regras e limites podem mudar.

Da ideia ao primeiro lançamento

O que falta para colocar o bot no ar?

Este é um projeto pessoal em preparação. O bot ainda precisa ser configurado antes do primeiro uso.

01

Crie o bot

Use o @BotFather no Telegram e guarde o token em local seguro.

02

Prepare o banco

Crie um banco Postgres no Neon Free. O projeto cria as tabelas quando recebe a primeira mensagem.

03

Publique o código

Implante o projeto na Vercel Hobby e configure o token e os segredos como variáveis privadas.

04

Converse em particular

Registre o webhook, envie /start SEU_CODIGO_DE_PAREAMENTO uma vez e depois /configurar.

i

Importante: nunca publique ou envie o token do bot, o código de pareamento ou a senha do banco. O site não pede nem armazena essas credenciais.
